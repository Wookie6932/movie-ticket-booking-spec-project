## Assignment Summary
This assignment defines the functional and nonfunctional requirements for the Movie Ticket Booking System, identifies the main stakeholders and actors, describes the key use cases, and presents the preliminary user interface specification.

- Project Progress

## Use Case Diagram
The use case diagram shows how the Customer and Theater Administrator interact with the five main use cases in the system. The figure is included as a linked interactive diagram, allowing the system boundary and actor relationships to be viewed directly.

Customers can:
- Create and manage an account
- Browse movies and showtimes
- Select seats and book tickets
- View and manage reservations

Theater administrators can:
- Manage movie listings
- Manage showtimes
